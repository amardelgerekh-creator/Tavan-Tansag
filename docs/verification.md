- TypeScript шалгалт: амжилттай.
- 12 тест: 10 хүсэлтийн API тест, 2 каталогийн өгөгдлийн тест — бүгд амжилттай.
- Next.js production build: амжилттай; хоёр хэлний хуудас, 20 эдлэлийн дэлгэрэнгүй, 6 нийтлэл үүссэн.
- Тусгаарласан PGlite орчинд migration, хүсэлт/харилцагч/үйл явдал/мэдэгдлийн атомик хадгалалт, давтан хүсэлт, rollback, rate limit, RLS эрхийн хязгаарлалт амжилттай.
- Seed-ийг хоёр удаа ажиллуулахад 10 бүртгэл хэвээр; нэвтрээгүй хэрэглэгч жишиг бүртгэлийг Supabase-ийн нийтийн уншилтаар харахгүй.

## Локал браузерын шалгалт

- `/mn` хуудас HTTP 200.
- Каталог 10 бүртгэл харуулна; аяганы ангилал ба `TT-006` хайлт нэг зөв үр дүн харуулсан.
- Хайлтад үр дүнгүй төлөв, хайлт цэвэрлэх үйлдэл ажилласан.
- TT-006 дэлгэрэнгүйгээс хүсэлт рүү ороход зөв эдлэл сонгогдсон.
- Маягтын хэлийг Англи болгоход `piece=TT-006` хадгалагдсан.
- Холболтгүй маягт илгээх товчийг идэвхгүй харуулж, Facebook холбоос өгсөн.
- Локал API руу туршилтын хүсэлт илгээхэд HTTP 503, `NOT_CONFIGURED`, `ok:false` буцсан; амжилтын хариу өгөөгүй.
- Өв соёлын картуудын зураг, агуулгыг шалгасан.
- 390 × 844 гар утасны хэмжээнд нүүр, каталог, дэлгэгддэг цэсийг шалгасан. Каталогийн өргөн 390px; хөндлөн халилт үүсээгүй. Цэсний холбоос сонгоход цэс хаагдсан.
- Desktop болон mobile харагдац `docs/previews/` дотор хадгалагдсан.

## Шалгаагүй буюу дараагийн шатанд үлдсэн зүйл

Бодит Supabase төсөл, JWT/нэвтрэлт, PostgREST холболт, олон зэрэг хүсэлтийн стресс тест, и-мэйл хүргэлт, Vercel байршуулалт, бодит домэйн, үйл ажиллагааны CRM дэлгэц, ажилтны барааны баталгаажуулалт энэ шатанд хийгдээгүй. PGlite шалгалт нь бодит Supabase орчны туршилтыг орлохгүй.

Жишиг зургууд дахь эдлэлүүдийг тусдаа агуулахын нэгж, баталгаажсан үнэт металл, тогтоосон он цагтай эдлэл гэж үзэхгүй. Дэлгүүрийн баталгаажуулалт шаардлагатай.
