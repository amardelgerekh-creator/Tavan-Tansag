# Таван Тансаг — вебсайтын эхний суурь

Монгол, Англи хэлтэй каталог, өв соёлын танин мэдэхүйн булан, Firebase-д хүсэлт хадгалах үйлчилгээ, ажилтны CRM. **Drive-ийн бодит зурагт тулгуурласан 10 жишиг бүртгэлтэй туршилтын вебсайт** юм.

Одоогийн сонголт: **GitHub + Firebase + Vercel**. Firebase төсөл нь `tavan-tansag-30560` (Spark); Firestore-ийн сонгосон байршил Tokyo — `asia-northeast1`. Эхний төлөвлөгөөний Supabase сонголтыг Firebase болгон өөрчилсөн. Хүсэлт хадгалалт, Google нэвтрэлттэй ажилтны CRM хэрэгжсэн; онлайн тохиргоо болон шалгалтыг `docs/backend.md`-д тэмдэглэнэ.

Үндсэн домэйн: **[tavantansag.com](https://tavantansag.com)**. GoDaddy DNS-ээр Vercel-д холбогдсон; `www` нь үндсэн хаяг руу шилжинэ. [Домэйны тохиргоо ба баталгаажуулалт](docs/domain.md).

## Харах, ажиллуулах

Node.js 24 болон npm ашиглана.

```sh
npm ci
cp .env.example .env.local
npm run dev
```

Local хаягийн `/mn` эсвэл `/en` хуудсаар үзнэ. Анхны тохиргоо `CATALOG_SOURCE=file` тул Firebase холболтгүйгээр каталог, агуулгын хуудсууд ажиллана. Хүсэлт илгээх товч идэвхгүй, Facebook холбоос харагдана.

```sh
npm run typecheck
npm test
npm run build
```

## Бэлэн боломжууд

- Drive-ийн бодит зураг, лого ашигласан нүүр хуудас.
- Brandbook-ийн Монгол/Англи вектор лого, “Мөнх Үргэлжлэх Монгол Өв” уриа, Heritage Bronze өнгө, Inter фонттой. [Брэндийн хэрэглээ](docs/branding.md).
- Хоёр хэлний каталог, ангиллын шүүлтүүр, нэр/кодоор хайлт.
- 10 эдлэлийн дэлгэрэнгүй хуудас; сонгосон эдлэл маягтад дамжина.
- Өв соёл, арчилгааны дөрвөн нийтлэл, танилцуулга, нууцлалын ажлын хувилбар.
- Гар утасны цэс, хэл солих, гарын товчлуураар удирдах боломж.
- Хүсэлтийн баталгаажуулалт, атомик хадгалалт, давтан илгээлт таних, давтамж хязгаарлах хамгаалалт. Хадгалалт батлагдсаны дараа дугаар олгоно.
- Google нэвтрэлттэй ажилтны CRM: төлөв, хариуцагч, эргэн холбогдох хугацаа, тэмдэглэл, өөрчлөлтийн бүртгэл.
- Каталогийн нийтэд харагдах талбаруудыг шалгаж дамжуулах бүтэц; эх сурвалжийн дэлгэрэнгүй бүртгэлийг браузерын өгөгдөлд оруулахгүй.
- GitHub Actions-ийн typecheck, тест, build шалгалт.

## Бүртгэл ба зураг

| Файл | Зориулалт |
|---|---|
| `data/catalog.json` | 10 жишиг бүртгэл, Монгол/Англи нэр, тайлбар, дотоод нягтлах мэдээлэл |
| `data/asset-manifest.json` | Drive эх файл, холбоос, ашигласан зургийн хувилбар |
| `docs/catalog-review.md` | Дэлгүүрээс баталгаажуулах мэдээлэл |
| `public/images/catalog/` | Вебд ашигласан зургийн хувилбарууд |
| `firebase/seed.json` | Firestore-д зориулсан, зөвхөн нийтэд үзүүлэх талбартай жишиг өгөгдөл |
| `firebase/seed-write.json` | Шинэ баримт үүсгэх REST commit хүсэлтийн өгөгдөл |
| `docs/backend.md` | Firebase холболт, хүсэлт ба CRM-ийн ажиллагаа |
| `docs/verification.md` | Шалгасан зүйл ба шалгалтын хязгаар |

TT-001–TT-010 нь **жишиг бүртгэлийн код**. Зургаар ялгаатай харагдаж байгаа нь тус бүрийг бодит агуулахын нэгж гэж баталгаажуулсан гэсэн үг биш. Нэг эдлэлийн өөр өнцгийг давхар бүртгэсэн эсэхийг эзэмшигч нягтална. Үнэ, материал, хэмжээ, жин, урлаач, он цаг `null`; үлдэгдэл `unverified`; нийтлэлт `sample`; баталгаажуулалт `needs_review` хэвээр байна.

Эх файл, Drive холбоос, нягтлах асуултууд нь серверийн эх бүртгэлд үлдэнэ. Эдгээрийг браузерын каталогт эсвэл Firestore-ийн нийтийн `catalog_public` цуглуулгад оруулахгүй. Репозиторын хандалт нь тусдаа асуудал: бодит CRM, хэрэглэгчийн мэдээлэл, нууц түлхүүрийг репозиторт нэмэхгүй.

## Firebase каталог ба холболтын төлөв

`CATALOG_SOURCE=file` нь локал жишиг бүртгэлийг уншина. `CATALOG_SOURCE=firebase` нь нийтэд үзүүлэхээр бэлтгэсэн каталогийг Firestore Enterprise Native REST pipeline-аар унших горим. Уншилтад API key, үйлчилгээний нууц түлхүүр хэрэглэхгүй; өгөгдлийн сангийн эрхийн дүрэм нийтийн уншилтын хүрээг тогтооно. Холболт тасарвал локал жишгээр далд орлуулахгүй.

`CATALOG_INCLUDE_SAMPLES=true` нь тусгаарласан туршилтын орчинд жишиг бүртгэлийг харуулах тохиргоо. Анхны утга `false`; энэ үед зөвхөн баталгаажсан, нийтлэгдсэн бүртгэлийг уншина. Тохиргоо нь Firestore-ийн эрхийг өөрөө өөрчлөхгүй.

`tavan-tansag-preview` сан нь `tavan-tansag-30560` төслийн Токиогийн `asia-northeast1` бүсэд `ENTERPRISE` / `FIRESTORE_NATIVE` горимоор ажиллаж байна; `freeTier=true` баталгаажсан. Firebase CLI/MCP нэвтрэлт, эрхийн дүрмийн compile/deploy, 10 цэвэрлэсэн жишиг баримтын create-only импорт амжилттай болсон. Бодит нэргүй уншилт 10 жишиг бүртгэл, нийтлэгдсэн бүртгэлийн шүүлтүүр 0 үр дүн буцаасан. Зөвшөөрөгдөөгүй хайлт, хувийн цуглуулгын уншилт болон нэргүй бичилтийн шалгалтууд 403-аар хаагдсан. [Backend баримтаас](docs/backend.md) нарийвчилсан тохиргоог харна уу.

GitHub болон Vercel CLI нь `amardelgerekh-creator` эрхээр холбогдсон. Каталогийн Production ба Preview тохиргоо Firebase-ийн жишиг 10 бүртгэлийг харуулна. Хувийн хүсэлт, CRM-ийн хандалт зөвхөн production байршуулалтын Vercel OIDC identity-д олгогдсон. Үйлчилгээний дансны хувийн түлхүүр үүсгээгүй.

## Хүсэлт ба CRM

`/mn/inquiry` болон `/en/inquiry` хүсэлтийг Firebase-ийн хувийн цуглуулгад хадгална. Хадгалалт болон хамгаалалтын бүх тохиргоо бүрдээгүй үед маягт хаалттай байна. Давтан хүсэлт ижил дугаараар хариулагдана; өөрчлөгдсөн агуулгыг ижил түлхүүрээр дахин бичихгүй.

`/mn/staff` болон `/en/staff` нь Google нэвтрэлттэй ажилтны хэсэг. Сервер зөвхөн `STAFF_EMAILS` жагсаалтын баталгаажсан Google бүртгэлийг зөвшөөрнө. Хүсэлт бүр шинэ төлөвтэй, хариуцсан ажилтантай үүснэ. Төлөв, хариуцагч, хугацаа, тэмдэглэлийн өөрчлөлтийг аудитын бүртгэлтэй хамт атомикаар хадгална. Нэвтрэлт зөвхөн нээлттэй цонхны санах ойд байна.

Ажилтан CRM-ээ нээж хүсэлтүүдээ шалгана; и-мэйл/SMS мэдэгдэл илгээх үйлчилгээ нэмж холбоогүй. Хүсэлт нь захиалга, төлбөр, барааны нөөцлөлт болохгүй. Онлайн төлбөр, хүргэлтийн автомат тооцоо, барааны агуулахын баталгаажуулалт дараагийн ажил хэвээр.

## Нийтлэхийн өмнө

`NEXT_PUBLIC_SITE_URL` нь тухайн байршуулалтын хаяг байна; тохируулаагүй үед Vercel-ийн `VERCEL_URL` ашиглагдана. `SITE_ORIGIN` тохируулбал мөн тухайн origin байна. Preview болон production өгөгдөл, эрх, тохиргоог тусгаарлана.

`SITE_INDEXABLE=false` нь хайлтын системд индексжүүлэхгүй байх заавар. Энэ нь хандалтын хамгаалалт биш; preview хамгаалалтыг байршуулалтын орчинд тохируулна. Харилцагчийн мэдээллийг GitHub болон нийтэд харагдах каталогт оруулахгүй.
